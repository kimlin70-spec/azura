# Azura Golf GPS

마다가스카르 Foulpointe의 Azura Golf Resort 전용, 개인용 골프 GPS 웹앱입니다.
안드로이드 폰 Chrome에서 쓰며, 설치 후에는 데이터 통신 없이 동작합니다.

- 현재 위치에서 선택한 홀의 **그린 중앙까지 거리**를 크게 표시 (앞·뒤는 선택)
- GPS 정확도와 마지막 갱신 시각 표시
- **샷 기록**: 공 앞에서 치기 전에 클럽 버튼을 누르면 위치·시각·클럽·그린까지 거리가 저장되고 1타가 올라감
- 벌타, 홀아웃, 되돌리기, 빠진 샷 추가
- 라운드별 스코어카드, CSV(엑셀용)와 JSON(백업) 내보내기·가져오기
- 외부 라이브러리 없음. `index.html` + `app.js` 두 파일이 전부

## 배포 (GitHub Pages)

1. 이 저장소의 **Settings → Pages → Build and deployment** 에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)` 로 지정합니다.
2. 몇 분 뒤 `https://kimlin70-spec.github.io/azura/` 에서 열립니다.
3. 폰 Chrome에서 그 주소를 열고, 위치 권한을 **허용**한 뒤, 메뉴(⋮) → **홈 화면에 추가**로 설치합니다. 설치된 앱은 주소창 없이 전체 화면으로 뜨고 오프라인에서도 열립니다.
4. 안드로이드 12 이상이면 설정 → 앱 → Chrome → 권한 → 위치에서 **정확한 위치**를 켜야 합니다. 라운드 중에는 배터리 세이버를 끄는 것이 좋습니다.

항상 같은 주소로만 쓰세요. 브라우저 저장소는 주소마다 따로이므로, 주소를 바꾸면 기록이 사라진 것처럼 보입니다.

`index.html`이나 `app.js`를 고친 뒤에는 `sw.js`의 `CACHE` 버전(`azura-v1`)을 올려야 설치된 폰에 새 버전이 내려갑니다.

## 좌표 넣기

18홀의 파와 그린 중앙 좌표는 구글어스에서 찍은 초기값이 앱에 들어 있습니다. 설정 → 코스 좌표에서 고칠 수 있고, 현장에서는 메뉴의 "그린 중앙 교체"로 바꿉니다.

- 구글 지도에서 그린 중앙을 **우클릭**하면 맨 위에 좌표가 보이고, 누르면 복사됩니다. 그대로 붙여넣으세요. 예: `-17.681234, 49.503456`
- 구글어스의 도분초 형식(`17°40'52.4"S 49°30'12.4"E`)도 그대로 붙여넣으면 됩니다.
- 남위는 음수여야 합니다. 부호가 빠지거나 다른 홀과 수 km 이상 떨어진 좌표는 입력 즉시 경고가 뜹니다.
- 현장에서 넣기: 그 지점에 서서 설정의 각 칸 옆 **📍** 버튼을 누르면 현재 GPS 위치가 들어갑니다. 플레이 화면 메뉴의 **그린 앞·중앙·뒤를 현재 위치로 기록**도 같은 기능입니다. GPS 정확도가 10 m보다 나쁘면 기다리라고 하고, 잘못 눌렀으면 5초 안에 "이전 값으로"를 누르면 됩니다.
- 현장 검증: 그린 중앙에 서서 표시 거리가 GPS 정확도보다 크게 나오면 그 홀 좌표가 틀린 것입니다.

## 기록 규칙

- 공 앞에 서서 **치기 전에** 클럽을 누릅니다. 그 한 번이 위치 기록이고 1타입니다. 탭 뒤 몇 초간 가장 좋은 GPS 값을 붙이며, 기록되면 진동이 옵니다.
- **첫 퍼트는 공 옆에서** 퍼터를 누르세요. 어프로치 샷의 끝점이 됩니다. 나머지 퍼트는 어디서 눌러도 됩니다. 퍼트 거리는 계산하지 않습니다.
- **홀아웃은 타수를 더하지 않습니다.** 컨시드 받은 퍼트도 퍼터를 눌러야 타수에 들어갑니다. 홀아웃하면 다음 홀로 넘어갑니다.
- OB·워터·언플레이어블은 **벌타** 버튼. 1타가 추가되고 직전 샷의 거리는 비워집니다. 드롭 위치에서는 평소처럼 클럽을 누릅니다.
- 치기 전에 누르는 걸 잊었으면 메뉴 → **빠진 샷 추가**를 지금 샷의 클럽을 누르기 전에 넣습니다. 위치 없이 1타만 들어갑니다.
- 잘못 눌렀으면 **되돌리기**. 되돌린 직후 5초 안에 "복구"로 다시 넣을 수 있습니다.
- 퍼터를 누른 뒤 그린에서 100 m 넘게 떨어진 곳에서 다른 클럽을 누르면 "홀아웃을 안 누른 것 같습니다" 확인창이 뜹니다.
- 라운드가 없을 때 클럽을 누르면 새 라운드가 시작됩니다. 끝나면 메뉴 → **라운드 종료**.

## 데이터

샷 기록 CSV의 열은 다음과 같습니다. UTF-8 BOM이 붙어 있어 엑셀에서 바로 열립니다.

| 열 | 내용 |
|---|---|
| 날짜, 시각 | 탭한 시각, 폰의 현지 시간 |
| 홀, 파, 홀타수 | 홀타수는 그 홀의 최종 타수 |
| 샷번호 | 홀 안에서 몇 번째 타인지. 벌타도 번호를 차지함 |
| 종류 | 샷, 빠진샷, 벌타, 홀아웃 |
| 클럽 | |
| 위도, 경도, 정확도m | 탭 위치와 GPS 정확도(68% 신뢰 반경) |
| 칠때그린거리m | 탭 위치에서 그 홀 그린 중앙까지 |
| 샷거리m | 다음 탭 위치까지 직선 거리. 다음이 벌타·빠진 샷이거나 퍼터면 빈칸 |
| 끝난뒤그린거리m | 다음 탭 위치에서 그린 중앙까지 |
| 비고 | 위치없음, 다음 벌타, 퍼트, 정확도낮음, 위치 n초 전 값 등 |

좌우로 얼마나 벗어났는지 같은 값은 위경도로 나중에 계산할 수 있습니다.

백업은 설정 → 데이터 → **전체 백업 JSON**. 코스 좌표, 클럽 목록, 모든 라운드가 들어 있고, 같은 화면의 **JSON 가져오기**로 되돌릴 수 있습니다. 라운드 기록은 되살릴 수 없으니 라운드가 끝날 때마다 백업하세요.

## 개발

```bash
node tests/e2e.cjs
```

Chromium과 Playwright가 있으면 GPS를 흉내 내어 거리 표시, 샷 기록, CSV, 좌표 파서, 설정 화면을 검사합니다.
코스 밖에서 직접 써 보려면 설정 → **테스트 위치**에 좌표를 넣으면 GPS 대신 그 위치를 씁니다.
